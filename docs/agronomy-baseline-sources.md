# Base agronomique — Sidi Bettach

Cette base est une référence initiale, modifiable dans les Fiches cultures. Elle a été choisie à partir de références de plantation fondées sur les températures de Rabat, Aïn El Aouda et Skhirate, de références techniques marocaines sur le maraîchage, de conseils horticoles généraux sur la rotation des cultures, et d’estimations prudentes lorsque les informations exactes sur le cultivar ne sont pas disponibles.

Les fenêtres indiquées sont des fenêtres principales de plein champ, pas des limites absolues. Elles devront être ajustées selon les températures observées, le gel, les pluies, l’irrigation, l’exposition et les résultats réellement constatés à la ferme.

La rotation proposée est basée sur les familles botaniques, avec un point de départ de trois ans avant le retour d’une même famille dans une zone.

> These values are starting estimates for Farm Fresh and should be refined using observations from the Sidi Bettach farm.
